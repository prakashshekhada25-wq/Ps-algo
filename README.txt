PS ALGO MOBILE V1 — PAPER TRADING
This is a browser-only prototype for iPhone testing.
It generates random simulated prices. It is NOT live market data and is NOT connected to Dhan or any broker.
For use: create a free Replit account in Safari, create an HTML/CSS/JS project, upload this index.html as the project's index.html, then use Replit's preview/webview. Keep the page open while the simulation runs. No API keys or broker passwords are needed.
